# Settled Lands 0.5.0

Minecraft **1.21.1**, NeoForge **21.1.252**, Java **21**. Файл `settledlands-0.5.0.jar`
собран в GitHub Actions (прогон `Build` #12, артефакт `settledlands-jar`) с коммита
`82ce611` — того же кода, на котором прошёл интеграционный набор (117 проверок на
настоящем выделенном сервере, маркер `PASSED`).

## Что нового

- **Стол зачарования больше не показывает дубликаты.** Для баннера существует только
  одно зачарование, поэтому строки совпадали (например, две строки «Святость II» по
  цене 23 и 30). Теперь из одинаковых строк остаётся самая дешёвая, остальные пустеют:
  пустая строка ничего не предлагает и клик по ней ничего не тратит. На мечи, броню
  и остальные предметы правило не влияет.
- **Описания уровней Святости.** Под названием зачарованного баннера появилась серая
  строка-подсказка: «Святость I» — «Спокойствие и безопасность»,
  «Святость II» — «Благословение и защита».

Остальное — как в 0.4.4: защита ячеек 16×8×16, поджог нежити уровнем II, ритуал
зомби-культиста, пороги силы (I от 1, II от 20), цены наковальни (2 уровня за I,
6 за II), конфиг и сохранения. Мир совместим, обновления данных не требуется.

Подробности: [CHANGELOG-0.5.0.md](CHANGELOG-0.5.0.md).

## Установка

1. **Обновите и сервер, и клиент** — моды должны совпадать по версии.
2. Положите `settledlands-0.5.0.jar` в папку `mods/`. **В `mods` должна лежать ровно
   одна версия мода** — старый `settledlands-0.4.x.jar` удалите.
3. **Перед обновлением сделайте бэкап мира.**
4. Править `config/sanctity.json` можно только при остановленном сервере.

Мод альфа-версии: механики могут меняться, всегда держите копию мира.
Что стоит проверить глазами — в `docs/PLAYTEST-RU.md`.
